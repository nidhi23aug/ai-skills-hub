# AI Skills Hub: notes for Claude Code

A catalog of AI skills that university colleagues use. People add skills or suggest changes through Google Forms and never need a GitHub account. This repo hosts the website.

- Live site: https://nidhi23aug.github.io/ai-skills-hub/
- Repo: https://github.com/nidhi23aug/ai-skills-hub (public, GitHub Pages from `main`, root folder)
- Local copy: `~/Downloads/ai-skills-hub`

## How data flows

```
Google Form  ->  Apps Script  ->  "AI Skills Hub Catalog" Google Doc
                                        |
               Apps Script pushes the doc text to data/catalog-doc.txt (GitHub API)
                                        |
               GitHub Action runs scripts/sync.py  ->  data/skills.json  ->  Pages site
```

- The **Google Doc is the catalog**. Editing a line in the doc changes the site. There is no approval step. To remove a skill, delete its line in the doc.
- The Apps Script pushes right after every form submission, and on a 15-minute timer to pick up direct doc edits. Run `pushDoc` in the script editor to push immediately.
- The Action (`.github/workflows/sync.yml`) runs on pushes to `data/catalog-doc.txt`, `data/seed.json` or `scripts/sync.py`, and from the "Run workflow" button.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole site: search box, two form buttons, skills grouped by category. Reads `data/skills.json` and `config.json`. |
| `config.json` | The two form links. Written by the Apps Script `setup`. |
| `data/catalog-doc.txt` | Plain-text copy of the Google Doc. Written by the Apps Script; don't edit by hand. |
| `data/seed.json` | Curated details for known skills (short description, "Made by", caution flag). For skills listed here, the seed description wins over the doc's text. |
| `data/skills.json` | Generated by `scripts/sync.py`; don't edit by hand. |
| `scripts/sync.py` | Parses the doc text into `skills.json`. Standard library only. |
| `apps-script/Code.gs` | The Apps Script source. The copy running in Google must match this file. |

## Doc format the parser expects

```
Category name
- Skill name - one short sentence - Added by Name, Department https://link
Suggestions
- Skill name: the suggestion - Suggested by Name, Department
```

A line without a bullet is a category heading. "Suggestions" is a special heading; its bullets attach to the skill with the matching name. Splits happen on a dash with a space on at least one side, so hyphenated words are safe.

Test the parser locally: `python3 scripts/sync.py` (reads `data/catalog-doc.txt`). To try sample input without touching the repo, copy `data/` and `scripts/` to a scratch folder first.

## Working rules

- To update the code in the Apps Script editor, load it with Monaco from the page, for example `monaco.editor.getModels()[0].setValue(code)` after fetching the file from raw.githubusercontent.com at a pinned commit, then save with Cmd+S. **Don't use the system clipboard**; the user copies tokens and other text while Claude works.
- Apps Script permission prompts open in a separate popup that Claude in Chrome can't reach. Ask the user to approve them.
- Contributor names and departments are public on the site. Don't collect emails.
- Write prose in plain language with no em dashes, following the user's global writing rules.
